# PhonePay-Transaction-Analysis-
Analyzing transaction trends, user behavior, and payment patterns using Power BI.

## 📌 Project Overview

This project analyzes **PhonePe transaction data** using **Power BI** to identify transaction trends, user behavior, and key business insights through an interactive dashboard.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel**

## 📊 Project Workflow

### 1. Data Cleaning & Transformation

Performed data preprocessing in Power BI using Power Query:

* Replaced incorrect/unwanted values
* Identified and handled null values
* Removed blank rows
* Removed duplicate records where required
* Changed data types
* Performed necessary transformations

### 2. Data Modeling

* Created relationships between tables
* Designed a structured data model
* Created a **Date Table using DAX**

### 3. DAX & Measures

Created DAX measures to calculate important KPIs and metrics for transaction analysis.

### 4. Data Visualization

Built an interactive Power BI dashboard to analyze:

* Transaction trends
* Transaction volume and value
* User activity
* Key performance indicators
* Overall transaction patterns
